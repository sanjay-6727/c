REFERENCE GUIDE — READ THIS FIRST
=================================
This folder contains small examples. Files under backend/ and frontend/ are the runnable project.
The .txt files are reference notes for studying and copying patterns during practice.

START ORDER
1. 01_SPRINGBOOT_MODEL.txt
2. 02_MONGODB_REPOSITORY.txt
3. 03_REST_CONTROLLER_CRUD.txt
4. 04_VUE_REACTIVE_FORM.txt
5. 05_FETCH_API_FUNCTIONS.txt
6. 06_VUE_ROUTER.txt
7. 07_PINIA_STORE.txt
8. 08_PROPS_AND_EMITS.txt
9. 09_VUE_PARENT_CHILD_EXAMPLE.txt
10. 10_COMMON_VUE_FUNCTIONS.txt

RUN
- Backend: run StudentApplication.java from IntelliJ.
- Frontend: cd frontend; npm install; npm run dev.
- MongoDB should be running at localhost:27017.

Remember:
Model = fields
Repository = database methods
Controller = API URLs
Router = page navigation
Pinia = shared state
Props = parent sends data to child
Emits = child sends event/data to parent
