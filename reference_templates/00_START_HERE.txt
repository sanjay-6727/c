START HERE — HOW TO USE THIS REFERENCE PACK
===========================================

WHAT IS IN THIS PROJECT?
- backend/: Java Spring Boot code. It exposes URLs that the frontend calls.
- frontend/: Vue 3 website. It has pages, a form, a table and navigation.
- reference_templates/: individual TXT lessons with examples and explanations.

RUN THE PROJECT
1. Make sure MongoDB is running at mongodb://localhost:27017.
2. In IntelliJ, open backend/pom.xml as a Maven project and run StudentApplication.java.
3. In a terminal, move into frontend/.
4. Run: npm install
5. Run: npm run dev
6. Open the localhost URL printed by Vite.

HOW A REQUEST TRAVELS
1. User clicks Add in Vue.
2. StudentForm emits a "save" event to StudentsView.
3. StudentsView calls the Pinia store.
4. Pinia calls studentApi.js.
5. studentApi.js sends POST /students to Spring Boot.
6. StudentController calls StudentRepository.
7. MongoRepository stores the document in MongoDB.
8. Pinia reloads the list; Vue updates the page.

QUICK DEFINITIONS
Model = Java class representing one record.
Repository = ready-made database operations.
Controller = HTTP endpoints such as GET and POST.
Lombok = generates repetitive Java methods.
Router = chooses which page appears for a URL.
Pinia = shared frontend state.
Props = parent sends data down to child.
Emits = child sends an event/data up to parent.
