LOMBOK MODEL — DETAILED BEGINNER EXPLANATION
============================================

PURPOSE
A model class defines the fields that belong to one database record.
For example, one Student has an ID, name, department and year.

RUNNABLE EXAMPLE
import lombok.AllArgsConstructor;
import lombok.Data;
import lombok.NoArgsConstructor;
import org.springframework.data.annotation.Id;
import org.springframework.data.mongodb.core.mapping.Document;

@Data
@NoArgsConstructor
@AllArgsConstructor
@Document(collection = "students")
public class Student {
    @Id
    private String id;
    private String name;
    private String department;
    private int year;
}

WHAT EACH ANNOTATION MEANS
1. @Document(collection = "students")
   Tells Spring Data MongoDB to store Student objects in the "students" collection.
   A collection is similar to a table in a relational database, although MongoDB stores documents.

2. @Id
   Marks the field that uniquely identifies a MongoDB document.
   MongoDB uses this ID to find, update or delete a particular student.

3. @Data (Lombok)
   Automatically generates getters and setters for fields, plus toString, equals and hashCode.
   Without Lombok, you would write methods such as getName() and setName(...) yourself.
   Lombok generates them during compilation; they usually do not appear in your source file.

4. @NoArgsConstructor
   Generates a constructor with no parameters: Student().
   Frameworks often need this when creating objects from incoming JSON.

5. @AllArgsConstructor
   Generates a constructor that accepts every field in declaration order.
   For this class, it is like Student(id, name, department, year).

WHY USE private?
private protects direct access to fields. Generated getters/setters allow controlled access.

HOW TO ADAPT
Book example:
@Document(collection = "books")
@Data
@NoArgsConstructor
@AllArgsConstructor
public class Book {
    @Id private String id;
    private String title;
    private String author;
    private double price;
}
Change the class, collection, and fields to match the question.

COMMON LOMBOK SETUP PROBLEM
If IntelliJ shows errors for @Data even though Maven has Lombok:
- Reload Maven.
- Install/enable the Lombok IntelliJ plugin if needed.
- Enable annotation processing in IntelliJ settings.
- Rebuild the project.
