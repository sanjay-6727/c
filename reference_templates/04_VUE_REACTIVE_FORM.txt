VUE FORM / REFS TEMPLATE
========================
<script setup>
import { ref } from 'vue'

// ref makes a value reactive so the page updates when it changes.
const name = ref('')
const year = ref(1)

function clearForm() {
  name.value = ''
  year.value = 1
}
</script>

<template>
  <form @submit.prevent="save">
    <input v-model="name" placeholder="Name" required>
    <input v-model.number="year" type="number">
    <button>Add</button>
    <button type="button" @click="clearForm">Clear</button>
  </form>
</template>

Notes:
- In JavaScript, use name.value.
- In the template, use name (Vue unwraps refs automatically).
- @submit.prevent prevents the browser from refreshing the page.
- v-model connects an input to a variable.
