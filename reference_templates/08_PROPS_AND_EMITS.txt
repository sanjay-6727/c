VUE PROPS AND EMITS — BASIC RULE
===============================
PROPS: parent -> child (send data down)
EMITS: child -> parent (send event/data up)

// ChildComponent.vue
<script setup>
const props = defineProps({
  message: String
})

const emit = defineEmits(['sayHello'])

function sendToParent() {
  emit('sayHello', 'Hello from child!')
}
</script>

<template>
  <p>Message from parent: {{ message }}</p>
  <button @click="sendToParent">Send event</button>
</template>

// ParentComponent.vue
<script setup>
import ChildComponent from './ChildComponent.vue'

function receiveMessage(text) {
  alert(text)
}
</script>

<template>
  <ChildComponent
    message="Hello child"
    @sayHello="receiveMessage"
  />
</template>

Remember:
- message="Hello child" is a prop.
- @sayHello="receiveMessage" listens for the emitted event.
- emit('sayHello', value) sends value to the parent.
